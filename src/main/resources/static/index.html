Timestamp Server – admin felület

Egyszerű felület a /api/timestamp/* végpontok eléréséhez: állapot lekérdezés, aláíró tanúsítvány megtekintése és az aláíró kulcs (PKCS12) cseréje.

Figyelem: ez a szerver teszt célú, az aláíró kulcs cseréje jelenleg nincs hitelesítéshez kötve. Ne tegyük nyilvánosan elérhetővé megbízható környezetben.
